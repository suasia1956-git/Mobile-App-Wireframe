# Mobile App Wireframe

## Thiranex UX/UI Design Internship - Task 1

This project contains a low-fidelity mobile application wireframe created as part of the Thiranex UX/UI Design Internship.

## Project Overview

The wireframe represents a simple mobile shopping application interface. It focuses on the basic structure and layout of a mobile shopping experience.

## Wireframe Sections

- Navigation
- Categories
- Featured Product
- Product Name
- Product Image Placeholders
- Bottom Navigation

## Design Approach

The wireframe follows a low-fidelity approach using simple shapes, lines, text labels and placeholders. The design focuses on the structure and placement of UI elements rather than colors, images or detailed visual styling.

## Screens

The wireframe includes the main mobile application layout with:

- Navigation section
- Categories section
- Featured product section
- Product information
- Product image placeholders
- Bottom navigation icons
